# Characters

One file per character: `{name}.md`.

Run the `create-character` skill to build one through dialogue (create mode) or pull it from the manuscript (extract mode). The skeleton it follows is `.project/templates/character.md`, if you prefer to fill one in by hand.

> **Write character sheets in the project's output language.**

---

## Naming convention

- Named characters: `aldric.md`, `tomas.md`
- Unnamed characters: use their designation — `the-investigator.md`, `the-merchant.md`
- Chorus / minor figures with recurring presence: `the-innkeeper.md`, `the-blacksmith.md`

---

## Which characters need a sheet

**Always:** POV characters, anyone with an arc, anyone appearing in more than three chapters.

**Usually:** recurring chorus figures whose voice must stay consistent.

**Rarely:** one-scene walk-ons — unless they carry a fact that could be contradicted later.

---

## The most valuable section

For most characters, **"Consistency rules"** earns its keep faster than anything else. It is what `check-consistency` reads, and what stops chapter 14 from contradicting chapter 3.
